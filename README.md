# Cheesecake Mod for Minecraft Forge 1.16.5

A delicious mod that adds cheesecake items, tools, armor, and blocks to Minecraft!

## Building

To build the mod:

```bash
./gradlew build
```

The compiled JAR will be located in `build/libs/cheesecake-1.0.0.jar`

## Features

- 🧀 Cheesecake and Cottage Cheese food items
- ⚒️ Full tool set (sword, pickaxe, axe, shovel, hoe)
- 🛡️ Full armor set (helmet, chestplate, leggings, boots)
- 📦 Cheesecake block
- ✨ Cheesecake material ingot

## Installation

1. Download the JAR from releases
2. Place it in your Minecraft `mods` folder
3. Enjoy!
